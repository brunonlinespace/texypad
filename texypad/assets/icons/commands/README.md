# Texypad command icon family

These are the packaged command icons used by Texypad.

- `light/`: light application theme — metallic-silver symbol on a dark notebook-style tile.
- `dark/`: dark application theme — dark symbol on a silver tile.

Each icon is a 64×64 RGBA PNG with transparent outer corners. Texypad selects the family from the active application palette and applies the same QAction icons to both the Ribbon and application menus.
